# LeetCode

My LeetCode solutions, written in C++, with notes on the key idea behind each problem.

## How I use this repo

- I commit a **brute-force attempt first**, then the optimized versions, so the history shows how the solution improved.
- I write a short `notes.md` for each problem (key idea, approaches, mistakes), using [TEMPLATE.md](TEMPLATE.md).
- I **re-solve old problems from scratch** to check I really learned them, and record the date in the Revisited column.
